# GTD Tag Memory

Maintained by the gtd-weekly-review skill.
One section per Taskwarrior tag; the heading is the exact tag name without the
leading `+`. Keep each description to one or two sentences explaining what the
tag means and when to use it. Append new tags; don't rewrite the whole file.

Taskwarrior `project:` is reserved for GTD projects: multi-step outcomes with
a clear done state. Work/customer/industry buckets belong in tags instead.

Example:

## next
GTD workflow tag for a concrete next action that is ready to do.

## customer-name
Work/customer bucket for tasks related to Customer Name. Use as
`+customer-name`; do not use `project:customer-name`.
